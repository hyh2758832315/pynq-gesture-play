# PYNQ 排错经验卡片

版本：0.1.0
署名：

把项目开发中已记录并归纳的重复问题接入日常排错。20 张卡片分为工具调用、
制品解析、启动连接、资源交接和实时输入五组，每张给出症状、处理路径、完成
条件和适用条件。模型入口为 [SKILL.md](SKILL.md)，直接阅读时也可按表选组。

本包保留 E01–E12 原卡片 ID，并接入 H13–H20 后续工程经验。来源技术摘要在 sources/，
文件摘要与逐卡映射在 [origins.json](origins.json)。摘要按问题保留观察与验证结果。历史现象未确定唯一根因时，卡片保留诊断分支。

卡片可直接复用，无需重新复现过去事故。PL 校验器的实测结果仍由同目录的验证
报告给出；卡片作为已有工程经验按症状调用。
许可见 [LICENSE](LICENSE)，署名留空。

## 适用条件与使用步骤

用于 PYNQ/Zynq 开发工具、Overlay 制品、元数据解析、启动连接、共享资源交接
及 PS 实时输入处理。按 SKILL.md 的症状表选择相关组，核对当前版本和对象，
执行处理步骤，再确认完成条件。无需安装运行库即可阅读使用。

当前版本、owner 或触发条件不符时，先核对实际源码和回执，再选择适合的路径；
历史地址、超时、IRQ 与进程身份不作默认值。未定唯一根因的案例提供诊断分支。
