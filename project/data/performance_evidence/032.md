# GPU 优化阶段的设计依据

本页归纳 2026-10-03 的 GPU 阶段实验，保留方案选择、关键修正和对应结果。

## 描述符复用

连续像素会反复使用同一 Tile 描述符。缓存以资源身份、地址 tag 和有效位识别可复用项，
资源更新后重新取数，减少重复访问。使用同输入的更新、翻转、透明和裁剪用例检查复用边界。
阶段 P1 的实现资源和时序保存在 gpu_cache_experiment/reports/c6i_tile_cache_p1 对应报告。

## 浅像素流水线

把取数、像素解析和写入拆分为浅流水，随数据传递目的地址、nibble 和 valid。
源原点与水平 run 终点提前锁存，使逐像素路径聚焦于索引选择；跨 Tile、跨行及错误结束时排空在途请求。
混合 Blit/Tile 测试以有序写入、CRC 和错误前缀共同检查这些边界。

## 条件双像素

双像素仅在地址、有效性与同行边界条件满足时使用，两路透明掩码独立处理，奇数尾像素回到单路。
CRC 保持 lane0 到 lane1 的顺序；并行 GF(2) XOR 结构缩短两笔级联更新的组合路径。
长 Tile 场景无掩码为 813→557 周期，有掩码为 781→525 周期，输出 CRC 分别保持
88CEA2AB、822C709E。完整像素读回覆盖每个 framebuffer 地址。

## 验证与取舍

局部验证先明确输入、时钟和比较对象，再由完整综合与布局布线确认资源及实际路径。
当时序报告指向坐标或 CRC 组合链时，只调整该路径结构，保持时钟、接口和黄金数据。
功能验证覆盖停顿、透明、裁剪、尾部排空、取消和错误前缀。
