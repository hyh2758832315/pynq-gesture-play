## 日常使用

已经安装并配置自启动的板卡，上电后自动检查和加载已安装项目，包括默认灵巧手；无需打开 Studio，不格式化 SD 卡。此次真实重启记录确认自启动服务 enabled、R15b 自启动实例运行、Studio HELLO 连接成功。未连接指定 USB 灵巧手时允许仅启动界面。换手需重新标定。

Studio 只保留一个 **启动／连接项目** 按钮：正在启动则等待，已经运行则连接，项目停止才启动。板卡 SSH 已连接、启动检查、内容初始化、Agent 就绪分别显示；启动锁被占用会等待并重新检查，不再直接报 Errno 11。是否允许回传以 Agent 就绪为准。

**安装完整项目** 用于上传/替换完整板端版本；启动／连接项目使用板卡现有版本。游戏、视频的构建、验证、加载均使用 Studio。初次整包安装先以无实体动作模式初始化；随后统一启动按钮使用板端默认灵巧手策略。已有受管自启动配置会沿用最新 active.json。全新 SD 卡的首次系统依赖安装不在此次验收范围；自启动配置源码和一次性安装工具保留于 source/board 和 source/tools/install_studio_autostart.py。

## PC 安装和入口

建议解压到短路径，例如 `E:\vv3`。先执行：

```powershell
python -B verify_release.py
cd studio
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[studio,vision,video]"
cd ..
studio\.venv\Scripts\python.exe -B start_studio.py
```

入口使用本包的 Studio、四游戏工程和 board_runtime，保持单窗口。配置 SSH 别名 `pynq-z2` 和密钥登录；默认板卡 `192.168.2.99:8765`、电脑直连源地址 `192.168.2.1`。启动 PC 窗口不自动上传或打开回传。

`verify_release.py` 校验全部发行文件，并从包内 SHA 校验块重建大视频；无需联网下载资产，首次运行需预留额外磁盘空间。日常修改游戏后使用 Studio 重新构建，不修改冻结部署清单掩盖代码变化。

## 交互与资源分配

- 主菜单及 GAME／VIDEO 列表握拳选择；返回键停留 2 秒，环形进度提示；游戏暂停、重玩、回菜单和结果页完整。
- 画布握拳选图形、调大小和连续绘画；临时相册只保留最新保存，完整重新初始化/重启后清空。
- 灵巧手跟随只读取最新手势，不积压动作；3 秒从有效手势获批开始计时，动作完整结束后可接下一态；同态保持，default 不额外占用保持期。启动时检查，播放时不持续读取电机反馈。来源过期进入可恢复等待。
- 0–9＋比心示范逐项先回 default，HDMI 像素手同步；视频/示范/跟随按页面交接权限，释放与启动异常有恢复路径。
- 相机回传尽快发送最新画面，暂停其他界面交互；HDMI 显示暂停页并保持手势圈同步，灵巧手可继续跟随。关闭回传恢复原界面。状态文字放在 Studio 侧栏。
- 实际玩法不使用声音输入；Game1 技能由 BTN0/BTN1 触发。无实验会话总时限，不注入测试手势。
