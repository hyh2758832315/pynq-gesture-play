## 日常开机：自动启动，不需要重新加载系统包

程序、bitstream、游戏和视频保存在 SD 卡里；没有每次格式化或重复上传。FPGA 的运行配置断电后丢失，开机从 SD 卡重新配置是必要步骤，与重刷 SD 卡不同。此前系统启动测得约 2 分 19 秒；整机和电机初始化还需时间。本轮实际重启复验中，Studio 连接检查等待约 4 分钟后自动 READY，加载按钮可用，默认手 ACTIVE。不以网口亮灯或 SSH 刚能连接作为全部就绪的依据。

灵巧手默认使用启动检查、固定播放、从批准起3秒、最新手势单槽、过期等待和回传互斥。**自启动模式不设置30分钟验收上限**，随视觉会话运行，正常停止须确认17 OFF。指定 USB 未接入时，本次只启动界面，并在启动记录里写明原因，不尝试其他串口。

服务为原来的 `voice-view-shell.service`，通过独立 drop-in 指向 `.studio-system/boot/system_autostart.py`；它读取 `.studio-system/active.json`，以后 Studio 安装成功的新版本会在下次开机使用。旧服务配置有备份。初始化失败或其他任务持有硬件时拒绝运行，不反复自动重载 Overlay。

## 手动验收入口：无需重新上传

1. PYNQ 上电后等待初始化结束；本轮 Studio 自动恢复就绪的等待约 4 分钟，并非固定时长。SSH 刚能连接时，官方 `boot.py` 可能还在加载 base；若 Studio 提示它占用硬件，继续等待，不要强制关闭。日常已有自启动时不必再使用此手动入口。
2. 双击桌面「启动Studio.bat - 快捷方式」，或项目根目录的 `启动Studio.bat`。启动器使用单实例，不必开多个窗口。
3. 进入左侧「加载到 PYNQ」，点「选择界面系统包」，选择上方完整目录（选择文件夹，不是里面的 bit 文件）。SSH 别名保持 `pynq-z2`。
4. 灵巧手独立电源已开启、USB 接在 PYNQ、范围清空并有人观察时，勾选对应现场条件，点「启动当前系统＋灵巧手」。
5. 等待 Studio 显示「灵巧手已就绪」，HDMI 从 Loading 进入主菜单，即可使用摄像头操作。无需 Codex 在线，也无需手工输入终端命令。

此手动入口通过 SSH 启动已安装的完整包；日常开机已有自启动时通常不必使用。顶栏「连接 PYNQ」只负责连接，整机自动启动由板端服务完成。

## 更换版本或首次安装

选择完整新包后先点「安装并启动界面」。Studio 校验完整清单和配对版本，检查板卡占用，正常交接并保留游戏、视频库。此按钮不驱动灵巧手。安装成功后，如需要实体手，再按上述第 4 步启动联合系统。

当前 R51 与板上包已配对；不要把候选目录里的单个文件手动换到板端。若提示「Current Studio system identity differs」，先核对是否选中了旧版本，再按需要完整安装，不能散文件替换后启动实体手。

## 当前验收模式的边界

- 手动「启动当前系统＋灵巧手」仍设置 **30 分钟实体手验收窗口**；与新的常驻自启动模式不同。到期实体手卸力，但整机进程未退出。下一次正常开机恢复配置的默认常驻模式。
- 回传关闭时测试实体手。开启图像回传会触发已有互斥流程，先暂停并卸力灵巧手；关闭回传后才允许恢复。
- 「取消任务」只用于正在进行的加载任务；启动成功后关闭 Studio 不代表板端程序已经停止。当前没有单独的整机停止 GUI 按钮。结束使用时应先在 HDMI 返回菜单、结束实体手动作后按项目既有关机流程操作；不要把 PC 窗口关闭当成卸力证明。
- 若报其他 owner 占用，先结束对应任务，不能并发装 Overlay。若报 cleanup/FORCED、正常退出超时或保留硬件，不要反复点击覆盖；保留加载日志，确认手已卸力后重启 PYNQ，再等官方初始化结束后启动。

连接目标：PYNQ `192.168.2.99:8765`，PC 直连源 `192.168.2.1`，BUILD `0xC0061000`。桌面启动器已带这些参数。接线、电脑网卡和 SSH 配置保持本次验证环境即可。
