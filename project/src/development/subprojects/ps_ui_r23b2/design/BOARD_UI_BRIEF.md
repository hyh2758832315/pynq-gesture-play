# PYNQ 粉色界面目标

## Direction contract

THESIS：一台可玩、可创作的粉色 PYNQ 设备；主菜单四块清晰入口，子菜单为不同位置的横向列表。

OWN-WORLD：官方 AMD PYNQ 组合标字形，玫粉、浅粉、暖白、深梅文字与少量青绿反馈；平面像素图形和轻边线。

STORY：玩家知道当前页、识别当前选项、握拳确认；换页松开后才能再次确认；返回继续保持两秒环形反馈。

FIRST VIEWPORT：左上固定返回，主菜单上方官方字标和简短标题，下方两列四入口；游戏列表改为三行。开机及进入内容显示独立全屏加载页。

FORM：用户指定品牌与既有嵌入式任务面，无随机网页风格选择。画板保持左4/5纸张、右1/5工具架。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

已纳入后续用户修正：暂停/结果页使用大图标和短标签；项目无声音玩法，玩家品牌显示 GESTURE PLAY，PC 显示 PYNQ Studio。独立修正审查与系统实板证据见 `docs/bringup/2026-10-27_r45_pink_shell_studio.md`（仓库根路径）。

## 验收清单

- 官方字标出现在开机加载和主菜单；来源、原文件和运行时掩模可追溯。
- 主菜单、游戏/视频列表、演示、画布和退出/暂停面板风格一致；游戏内部保持现状。
- 子菜单布局不同；持续握拳、分类闪烁和过期/重复帧不能在换页时连点。
- 游戏准备前已经提交全屏加载帧，准备失败恢复可操作菜单；游戏首帧接管资源时无并发渲染。
- 画布保留四色形状、大小、剪刀单次与握拳笔刷，返回清空/菜单流程完整。
- 静态页面只在视觉状态改变时提交；字标静态缓存，图集/命令/预测周期预算经过真实打包器验证。
- Studio增加界面系统候选的加载入口，身份校验、占用门禁、正常停止、保留内容库、日志和恢复路径均有测试；本轮上板必须由此入口执行。
- 离线原生渲染批量检查、针对性交互测试、Studio实际加载与板端证据逐项记录。

## 素材依据

官方项目： https://github.com/Xilinx/PYNQ 。用户已明确选择当前带AMD的官方组合标，保留完整几何比例，运行时将AMD映射深梅色、PYNQ映射粉色；这属于本项目的颜色适配，不声称是官方发布的新配色版本。原图SHA为 `0e688b32953ca08f597254d21e563b5182b253b518192e5b5e1494fa6551aae1`。

配色方法参考 Adobe Color 的色轮与图像提色方式：https://color.adobe.com/ 。以下具体搭配为本项目设计选择，文字/背景对比度另由脚本计算，不能只凭配色名称认定可读。
