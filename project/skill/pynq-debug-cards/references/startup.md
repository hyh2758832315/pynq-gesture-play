# 启动、连接与界面响应

按当前症状选择卡片，先核对触发条件，再采用对应处理。

<a id="e09"></a>
## E09 · 初始化较慢，被当成运行失败

- **症状：**短启动期限先到，稍后进程实际 ready；等待期间看不到阶段变化。
- **核对与处理：**分别设置冷启动、稳态和退出预算；沿现有 owner 观察阶段、ready 与退出状态。显示已等待时间/进度，阶段持续前进时按启动策略继续等待。
- **完成条件：**当前实例就绪且目标功能有产出；真正超期进入有界恢复或明确错误状态。
- **适用条件：**按当前设备的冷启动测量配置时间预算；案例中的 5 秒与 8.6186 秒用于说明观测方法。
- **来源：**[来源案例](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e10"></a>
## E10 · PC 能运行，板端缺依赖

- **症状：**实际入口导入失败，或把 PC 打包依赖也要求安装到板端。
- **核对与处理：**用任务实际解释器核对构建/运行/诊断依赖、发行元数据、导入路径与包来源；按运行需要补齐对应固定依赖。
- **完成条件：**目标入口的依赖检查通过，并继续验证实际功能。
- **适用条件：**在当前环境中核对兼容版本，定向补齐所需依赖并保持已验证组件稳定。
- **来源：**[来源案例](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e12"></a>
## E12 · 测试入口通过，日常入口却不能用

- **症状：**显式测试启动正常，Studio/桌面/自启动缺平台、端点或源绑定。
- **核对与处理：**对照真实产品入口的配置传递和启动回执，逐层匹配目标身份、输入模式、端点和数据来源；从用户实际入口完成操作。
- **完成条件：**日常入口取得正确当前实例并完成目标功能。
- **适用条件：**进程存活、帧新鲜、功能正确和现场体验是不同观察项；按任务选取。
- **来源：**[来源案例](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="h13"></a>
## H13 · Errno 11、一直重连或重复启动

- **症状：**启动遇到 loader 锁忙，active 记录还属于旧 boot，界面误报未运行。
- **核对与处理：**核对当前 boot、服务/launcher owner、锁和已有启动阶段；锁忙时加入原事务的观察并连接，已运行则直接复用。允许现有控制器在就绪后执行正常重配置。
- **完成条件：**同一当前实例进入 ready，界面准确区分 SSH 可达、初始化中、应用就绪和可回传。
- **适用条件：**锁状态用于确定观察分支，具体持有者通过当前 boot、PID 与事务记录核实。
- **来源：**[来源案例](../sources/unified_start.txt)。

<a id="h14"></a>
## H14 · 点击启动后 GUI 冻住

- **症状：**启动最终成功，但期间进度、心跳或取消按钮没有响应。
- **核对与处理：**检查真实按钮到 worker 的线程分派，把慢 I/O 留在后台；核对 Qt 槽继承/连接语义，更新界面采用信号并保持取消观察可响应。
- **完成条件：**等待期间界面心跳与取消正常，结束后本机线程收回。
- **适用条件：**分别定义取消观察和取消板端启动，利用现有进度信号保持界面响应与低通信负荷。
- **来源：**[来源案例](../sources/studio_start.txt)。
