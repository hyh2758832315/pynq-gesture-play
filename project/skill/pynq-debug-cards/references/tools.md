# 工具调用与会话

按当前症状选择卡片，先核对触发条件，再采用对应处理。

<a id="e01"></a>
## E01 · 阶段变了，命令却被判重

- **症状：**阶段已从综合切到实现，同一 source 请求返回 SKIPPED、零耗时或旧结果。
- **核对与处理：**核对原命令的操作身份、阶段、输入和当前忙闲状态；按当前工具支持的续接方式提交具有正确阶段身份的任务。
- **完成条件：**实际完成记录、新阶段标记和对应产物同时存在；SKIPPED 不计为新执行。
- **适用条件：**判重机制取决于当前 MCP 实例，先发现其 schema 与执行语义。
- **来源：**[来源案例](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e02"></a>
## E02 · 工具成功，但仿真或实现仍失败

- **症状：**success=true 或退出码为 0，日志却有 Fatal、领域 FAIL，或没有目标产物。
- **核对与处理：**分别核对传输完成、命令退出、原始日志、目标产物和功能断言；长输出读取完整日志，预期故障按用例断言判定。
- **完成条件：**目标领域的通过条件满足，并按 Warning 的实际影响完成审查。
- **适用条件：**适用于工具封装、捕获异常后正常退出及异步执行。PL 保持性检查可调用配套 pynq-pl-preserve。
- **来源：**[来源案例](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e03"></a>
## E03 · 有计划却找不到计划，或拿错会话

- **症状：**向 global 更新时报 no plan found，或历史 session 存在而当前对象不匹配。
- **核对与处理：**从本次回执取得真实 session/任务身份，核对工程和忙闲状态；同一会话串行执行，运行中沿原句柄观察。
- **完成条件：**更新落在正确会话，实际命令终态与该操作身份对应。
- **适用条件：**使用持久索引查找记录，重启后重新匹配当前 boot/session。
- **来源：**[来源案例](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e04"></a>
## E04 · 命令或选项在当前版本被拒绝

- **症状：**命令不存在、schema 拒绝参数、选项无法解析，尚未进入目标算法。
- **核对与处理：**读取当前工具 schema、本机命令帮助与实际版本，再修正调用；同时区分客户端路径和执行主机路径。
- **完成条件：**参数解析完成并执行目标步骤，随后核对其领域结果。
- **适用条件：**案例中的 list_property_values 和 XSim -O 用于说明版本差异；可用命令和选项以当前工具帮助为准。
- **来源：**[来源案例](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。
