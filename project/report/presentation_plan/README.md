## 每段最值得展示的机制和指标

1. **直驱灵巧手**：PYNQ PS 经 USB 串口及 SDK 控制 17 电机，驱动不依赖 PC。
   独立供电线与通信线分别绘制；通信路径为 PS→USB 串口→舵机总线。
   串口速率标注为“配置 1 Mbaud”；有效吞吐率按传输字节与耗时另行统计。
   17 标注为电机数量；机械独立自由度结合关节运动箭头、结构和实拍确定。
2. **视觉识别**：PL 固定前处理及双掩膜，PS 轮廓/凸包/凸缺陷与分类。
   使用同一帧的原图、掩膜和分类对照；指标为实际识别 FPS、分类正确率、无手误触发和 P95 延迟。
3. **HDMI 跟随**：独立 OSD 的最新位置、握拳状态与应用画面叠加。
   画出应用暂停时 OSD 仍更新的分支；测物理手移动到屏幕位置变化的时间及位置抖动。
4. **实体跟随**：输入只保留最新状态；动作获批时开始窗口 t（当前配置 3 s），动作完成且窗口到点后处理最新状态，同态保持，default 无额外窗口。
   用时序图显示“忙中变化→最新槽被覆盖→下一可执行时刻消费”。分别标识调度等待与实际运动时间。
   正常播放采用指令发送与阶段计时，位置读取集中于启动和退出检查。
5. **GPU 视频渲染**：视频准备/解码与 PL 图形呈现分层展示；PL 承担 Scene2D 渲染与显示输出。
   分别标注命令缓冲、资源缓冲和显示双缓冲的职责与生命周期。
   320×180×8-bit×2 = 115,200 B 是逻辑双帧缓冲容量；BRAM 实际占用另由综合报告给出。
6. **游戏流畅度**：实拍持续运动，统计真实呈现帧间隔、输入响应、长停顿、丢帧或重复帧。
   720p60 标注为 HDMI 扫描配置；设计 tick 目标与实际更新率分别列出。
7. **画板流畅度**：图示驻留背景与固定像素画布，以固定存储合并图案并按变化内容更新。
   测盖印延迟、长时绘画的帧间隔、对象/缓冲容量、每次更新上传字节。
8. **Studio**：展示同一内容包、用例和逻辑时间的 PC/PYNQ 验证链路。
   指标包括标准安装成功、相同内容身份、逐 tick 结果一致及启动/返回恢复。

## 灵巧手通信图的准确画法

上层：视觉生产者 → 单个最新状态槽 → owner/调度器 → 预编译阶段目标 → USB/SDK。
下层时间线：启动检查 → 播放阶段目标并按时序等待 → 正常保持/接受后续状态 → 退出卸力确认。
将 READ/WRITE 用不同箭头区分：正常播放省去持续位置轮询，启动与退出仍有检查。
“played/阶段计时结束”表示调度阶段完成；机械到位由位置测量独立确认。运行 CPU 与命令率按同版本、同输入配对测量。

## GPU 缓冲图的准确画法

- 命令 bank：PS 打包 Scene，DMA 批量上传；占用期间保持 bank 内容，释放后接受后续上传。
- 资源 bank：贴图/调色板/Tilemap 按代际生效；一个 Scene 引用一致的资源身份。
- 帧缓冲：渲染写后台，HDMI 扫描读前台；绘制完成后在消隐期交换。
- 回执：accepted、rendered、displayed 分别表示接收、绘制和真正呈现。
- 当前三个配置均关闭上传/渲染重叠。模式交接按完成回执排空在途事务后再转交资源。
- 分别标注片上 BRAM 与外部 DDR；RGB 源图像与索引色逻辑帧各自注明尺寸和编码。

## 评委关注点与对应证据

依据官方自主选题评分：创新性与应用价值 30，性能与资源优化 20，功能正确性与完整性 20，
大模型协作与技能包 15，文档质量与可复现性 15。以下为据此推导的展示重点：

- 单板为何需要 PL/PS 协同，硬件承担什么，PC 退出后系统还能完成什么（F01–F04）。
- 同负载下改进了多少、付出了多少资源、时序是否满足（F05、T01）。
- 持续运行、模式切换、返回与断源恢复的完成情况（F07–F09、T03）。
- 是否能由 Studio 从内容创作走到标准部署并复查结果（F06、T02）。
- Skill 从真实问题提炼且可复用：视频留一张短证据卡，报告与海报链接当前 skill/README.md；
  可展示“复位边界激励→全输出校验在 5.001 ns 定位差异”，作为验证方法的简要示例。

## 三端统一制作规则

每个 F/T 编号保留同一事实来源和标题，输出可编辑 SVG/draw.io 与 PDF/PNG；视频在母图上
分步出现元素，海报取简化版，报告保留尺寸/协议/时序细节。坐标轴、单位、颜色、版本
和测量条件一致。PL、PS、外设、数据流、控制流沿用统一配色及线型。

性能图标明量纲、工况与测量平台，微基准、PC 本地计算和集成板端数据按测量范围分组。
流畅性采用呈现帧间隔、长停顿次数及输入响应时间等可复测指标。

## 录制与采集

优先用摄像机同框记录真实手、HDMI 和实体手，记录机位帧率以确定时间分辨率。
真人演示采用运行时已有的缓存时间戳和计数；高频 MMIO、位置反馈及持续探针等附加测量单独安排。CPU 指标注明“单核归一、双核最高 200%”或其他一致口径。
跟随延迟分为识别、调度等待、发令和机械运动，窗口 t（当前配置 3 s）归入调度时间。

本页提供图表制作与采集方法。工程、Skill 和验证结果分别见 [工程 README](../../README.md)、[Skill](../../skill/README.md) 和 [验证汇总](../validation.md)。
