# 构建输入、制品与解析

按当前症状选择卡片，先核对触发条件，再采用对应处理。

<a id="e05"></a>
## E05 · 文件存在，但综合仍找不到 header

- **症状：**磁盘能找到 header 或仿真能编译，实际综合报 include/文件管理错误。
- **核对与处理：**沿实际构建入口核对目标文件集、top、include 基准、header 和初始化文件的注册；在同一目标中重新解析。
- **完成条件：**原缺失引用消失；随后出现的时钟或接口问题按新错误继续定位。
- **适用条件：**文件集不一定叫 sources_1；不能用磁盘存在或另一个仿真目标通过代替。
- **来源：**[历史记录](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e06"></a>
## E06 · BD 已改，HWH 还是旧地址

- **症状：**工具报告 up-to-date，但软件合同与生成 HWH 的地址、接口或参数不一致。
- **核对与处理：**在完成连接传播后读回参数，核对实际 HWH 和当前接口合同；确认生成图与目标后重新生成对应产物。
- **完成条件：**当前 BD、正式 HWH 和软件使用的接口一致，并关联到同次构建。
- **适用条件：**不套用案例中的固定地址；已有正确产物时无需重复 reset 或生成。
- **来源：**[历史记录](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e07"></a>
## E07 · 下载前出现 UnknownInputFileExtension

- **症状：**同目录邻接 XSA 后，Overlay 在元数据解析阶段报输入扩展名错误。
- **核对与处理：**检查实际 PYNQ 安装源码的解析分支、同 stem 邻接文件及 bit/HWH 配对；需要隔离诊断时保留原件，在新目录使用摘要一致的正式配对进行纯解析。
- **完成条件：**正确配对完成元数据解析，再按任务执行加载与业务核验。
- **适用条件：**历史现象属于特定 PYNQ 3.1 安装版；不推导为所有版本都应删除 XSA。
- **来源：**[历史记录](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="e08"></a>
## E08 · HWH 有 IRQ，运行对象却没有

- **症状：**HWH、parser、Overlay 或 IPMap 的中断描述不一致，嵌套 update 后读回仍空。
- **核对与处理：**沿 HWH 来源和当前解析器逐层核对 IRQ、IP 地址和运行视图；查清 copy-on-read 语义后更新持久描述并按支持流程重建运行视图。
- **完成条件：**需要的各层描述与实际 HWH 一致，使用者能得到正确中断信息。
- **适用条件：**按实际安装版和中断拓扑处理，不手填历史 IRQ 编号。
- **来源：**[历史记录](../sources/preflight_cards.txt)。

原始调用身份与来源摘要另见 [E 系列目录](../sources/preflight_catalog.txt)。

<a id="h20"></a>
## H20 · 导出的 XSA 带了中间版本 bit

- **症状：**导出成功，但归档内 bit 与最终收敛设计或外部运行包不一致。
- **核对与处理：**区分工程 run 的中间结果和最终 routed DCP；核对导出上下文，选择顶层成员，从同一正式归档提取 bit/HWH 并比对配置负载与接口。
- **完成条件：**归档内外正式配对一致，构建来源指向最终设计。
- **适用条件：**容器时间戳变化与配置负载变化分别判断；文件名或日期不能单独证明配对。
- **来源：**[历史记录](../sources/export_validation.txt)。

实际配对收据见 [export_pairing](../sources/export_pairing.txt)。
