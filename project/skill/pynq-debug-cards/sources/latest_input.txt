# 最新状态在可执行边界的消费

观察：MOVING 时更新 last_frame，READY 时同一帧被判 duplicate_frame；动作期间到达的最新分类因此漏执行。另一条路径将 FRAME_EDGE 与 NO_HAND 合并，误清可靠分类。

| 时刻 | 状态 | 处理 |
| --- | --- | --- |
| 10.00 s | 帧 1 握拳，READY | 批准动作 |
| 12.95 s | 帧 2 剪刀，MOVING | 更新最新槽，保留源时间 |
| 13.00 s | READY，帧 2 年龄 50 ms | 消费一次最新帧 |
| 16.10 s | FRAME_EDGE，分类可靠 | 方向授权与分类分别处理 |
| 16.30 s | 明确 NO_HAND | 执行 default |

修正：已观察帧与已执行帧分别记账；输入仅存最新槽，不积压动作。UNKNOWN 保持，NO_HAND 回默认；换源、过期和错误帧清理旧状态。

验证：九种保持/切换 × 四种边缘组合 × 四种截止时机 × 两种闪烁，共 288 条时间线，加六项异常边界，294 项通过；实际 SDK 内存串口覆盖六种定向切换 × 中央/边缘，共 12 组通过。综合回归 431 项通过。
