# PYNQ 排错经验卡片

版本：0.1.1
署名：

将项目开发中的工程观察整理为可复用的诊断方法。20 张卡片分为工具调用、
制品解析、启动连接、资源交接和实时输入五组，每张给出症状、处理路径、完成
条件和适用条件。模型入口为 [SKILL.md](SKILL.md)，直接阅读时也可按表选组。

本包保留 E01–E12 原卡片 ID，并接入 H13–H20 后续工程经验。来源技术摘要在 sources/，
文件摘要与逐卡映射在 [origins.json](origins.json)。摘要按症状保留观察与验证结果，多因素场景提供逐项排查分支。

卡片将工程经验转化为适用条件、处理步骤与完成检查。使用时核对当前工程状态，
按匹配分支定位，并验证处理结果。PL 校验器的量化实验见同目录验证报告。
许可见 [LICENSE](LICENSE)，署名留空。

## 适用条件与使用步骤

用于 PYNQ/Zynq 开发工具、Overlay 制品、元数据解析、启动连接、共享资源交接
及 PS 实时输入处理。按 SKILL.md 的症状表选择相关组，核对当前版本和对象，
执行处理步骤，再确认完成条件。无需安装运行库即可阅读使用。

当前版本、owner 或触发条件与案例有差异时，先核对实际源码和回执，再选择
适合的路径。地址、超时、IRQ 与进程身份使用当前工程值；多因素场景逐项验证。

## 与 ROSS 联合使用

[ROSS / Vivado MCP 工作流](references/ross_workflow.md)将卡片接入工具任务的三个阶段：执行前核对版本与工程身份，运行中沿原任务读取状态，结束后检查功能、时序与制品配对。模型按需读取卡片，再使用当前 ROSS 工具执行；适用的叶模块重构可接入 `pynq-pl-preserve` 生成参考比对和验证收据。使用独立仿真会话，保持已有综合/布线任务的工程状态。
