# 声音2026.1改进方案与阶段计划

更新时间：2026-10-05。板卡：PYNQ-Z2 / xc7z020clg400-1。工具：Vivado2026.1。
本页用于队友接续声音链开发；当前交付为独立声音源码、原生迁移证据和复建入口。

## 已完成基线

原生IP/BD生成、综合、路由、6PCM启动和485条合成特征打包均已通过。路由WNS/WHS为2.654/0.015ns，TNS/THS为0，零黑盒。独立ZIP解压到新路径后，prepare实际68.336s/exit0；capture实际26.668s/exit0，485条/3880字/31040B、2735背压，其SHA与原确定性输出一致。

输入设计合同为48kHz左声道PCM，算法40MHz、AXI100MHz、MCLK10MHz。DC blocker、1201tap Q17 FIR、六倍抽取、512点窗/32步进、去均值/Hamming、定点FFT/CORDIC及64B记录保持。采集2秒对应485记录，原wrapper默认985，入口显式485。

原2024.1 bit/HWH和模型保留为回退，包内runtime文件身份保持。完整PCM数值、独立2024.1整数参照、DDR/I/O/CDC签核和新候选实板仍待完成。当前交付的2026.1 DCP是验证证据，新bit/HWH/XSA发布另设门禁。

## 改进方案

### 持续运行与短包传输

复用同一套数字前端，后续将批末停止和每批复位的采集末端改为持续RUN、短包分包器及有界FIFO。初始候选每包8条记录，即512B、稳定流期间32ms一包，TLAST置于最后一条记录的最后一拍。短包内布局保持，跨包帧序号、会话、复位与回绕另设合同。

初始FIFO候选512x64bit，即4KiB/64条记录，名义稳定流缓冲256ms；实际深度由并发负载的DMA重新arm停顿、水位、缺口和记录年龄定型。RUN期间保持FIR历史及帧索引，STOP/故障才受控重建会话；溢出或帧缺口显式使事件失效。

### PS增量判决与安全恢复

持久双DMA缓冲、有界记录ring和后台worker隔离采集与消费者。DMA写入或分类仍持有的buffer不复用；invalidate、专属S2MM Halted确认、安全停止和异常恢复分别测试。

新短窗统计以sample counter定位因果窗口，候选特征包括功率、过零率、频带比例、质心和稳定性。原2秒模型输入聚合依赖整窗，短窗模式用授权固定语料重新验证判决分布、拒绝策略与事件去重；原模型及2秒流程继续保留。

实时性优先：先验证1秒档，再在同等识别质量、故障安全及资源条件下推进0.5秒增强档。这些是后续命令响应目标，当前没有完整链或真人HDMI延迟实测。声音资源按完整路由和未来视觉需求配置，保持足够视觉余量；不另设任意BRAM、DSP、CPU或RAM硬上限。

### 观察与双域接入

先输出有来源、模型/会话身份、采样索引及健康状态的特征摘要；真实PCM和逐bin频谱观察支路单独建设与验收，分析订阅不阻塞实时动作或诊断消费者。

声音与现有视觉交接各为独立Overlay基线。未来共享硬件使用单PS、单Overlay所有者，先依据两份实际HWH审计地址、HP端口、时钟、管脚、DDR竞争和资源，再定义合并身份。声音独立基线仍使用HP0和原地址，HP1及新地址仅为原游戏合并规划的候选。

旋转设备诊断可复用声音采集、特征流、时间关联和健康管理。现有attack/shield/none属于声音命令分类，故障标签、声视一致性判据、转速工况和领域数据另立任务合同及测试集。目标仓库名或描述不改变现有模型的验证范围。

## 先完成P1

1. 延续同周期性能探针，区分analysis、elaboration、kernel；低频进度与墙钟预算来自测量，保留原采样节拍及断言。当前短测不用于承诺完整测试时长或加速倍数。
2. 静音和完整方波必须真实终端PASS，输出192000B方波PCM及31040B特征；packer、bootstrap、退出码0各自只证明其实际覆盖范围。
3. 获得队友合法2024.1同刺激、同ROM/model和IP配置的整数参照。2026结果不自作跨版golden；工具数值差异先定位尺度、舍入和配置。
4. 先处理TIMING-18四个I/O延迟，再审计TIMING-24三条被clock_groups覆盖的max_delay；57项CDC-15按实际XPM条件及约束逐类核查。DDR四负DQS值核对板preset及实板训练，保持风险可见。
5. 核查BRAM复位/访问、FIFO busy和重复capture/停止。必要局部修复后定向回归并独立路由签核，再生成匹配bit/HWH/XSA及身份清单。

每轮错误、MCP跳过、修复和复验追加到包内evidence阶段记录。原始报错不覆盖，SKIPPED不作为新运行，实板与离线结果分开登记。
